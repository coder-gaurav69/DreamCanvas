# 🎨 DreamCanvas – AI Image Generator  

**Tech Stack:** React, OpenAI API  

## 🔹 Description  
DreamCanvas generates stunning images based on your text prompts using OpenAI's image generation model. It provides an intuitive interface for users to unleash their creativity and instantly visualize their ideas.  

## 🎯 Goal of Project  
The goal of **DreamCanvas** is to create a **simple and powerful AI image generation tool** that allows users to transform their imagination into visuals instantly. It focuses on **ease of use**, **beautiful UI**, and **quick image generation** without technical barriers.  

## 🛠 Process of Project  
1. **Concept & Design** – Designed a minimal, mobile-friendly interface for prompt input and image display.  
2. **Frontend Development** – Built with **React** to handle prompt submission, image rendering, and history tracking.  
3. **API Integration** – Connected to **OpenAI's Image Generation API** for text-to-image transformation.  
4. **User Experience Enhancements** – Added features like prompt history, download options, and instant feedback.  
5. **Deployment** – Hosted on **Render** for easy public access.  

## 📌 Features of Project  
- 🖌 **Text-to-Image Generation** – Convert any prompt into a unique image.  
- 📜 **Prompt History Tracking** – View previously used prompts and generated images.  
- 💾 **Image Download** – Save your generated images locally.  
- 📱 **Responsive UI** – Optimized for both desktop and mobile devices.
