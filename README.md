# 🎨 DreamCanvas – AI Image Generator

**Tech Stack:** React, OpenAI API

## 🔹 Description
DreamCanvas generates images based on your text prompts using OpenAI's image generation model.

## 🔧 Features
- Text-to-image generation
- Prompt history tracking
- Download generated images
- Clean, mobile-friendly UI
